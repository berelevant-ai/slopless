# License: AI-generated corpus (we own it)

All documents under `ai-generated/` were generated by us for true-positive testing of the
slopless linter. Provenance is recorded in an HTML comment at the top of each file
(`<!-- ai-generated; model=...; topic=...; format=... -->`).

- `ai-generated/<topic>/claude/` - generated by Claude (Haiku and Sonnet), 15 topics.
- `ai-generated/business/synthetic-claude/` - earlier Claude-generated marketing slop set.

## License / publishability

- **Owner**: us. Model outputs are owned by the API customer under the providers' terms
  (Anthropic). 
- **Redistribute**: Yes. **Publishable**: Yes, but label clearly as **synthetic /
  AI-generated**, and note it is **single-model (Claude)** so the vocabulary distribution
  is not representative of all AI writing. Honor the model provider's usage terms.

This set is a labeled positive (slop) set, NOT human writing - do not mix it into the
human false-positive baseline.
