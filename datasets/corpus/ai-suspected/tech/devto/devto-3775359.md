# Chingu.io: Build, Collaborate, Learn: Remote Projects V60 Showcase

Celebrating the successful completion of Voyage 60, held from March 23rd to May 10th, 2026, we're excited to showcase the innovative projects created by our teams. This voyage featured a new seven-week format, including an additional onboarding week that gave participants time to connect with their teammates, establish workflows, and prepare for collaboration before project development began. Over the course of the voyage, developers from around the world worked remotely to transform ideas into functional applications while strengthening both their technical and professional skills. Join us as we highlight the creativity, dedication, and achievements that made Voyage 60 a memorable journey. If you're interested in taking part in a future voyage, we'd love to have you join the [Chingu community](https://www.chingu.io/).

# cramerbot

![Image description](https://dev-to-uploads.s3.amazonaws.com/uploads/articles/7mjkid80ltbrtb3cfxop.png)


*Inspired by a joke made on reddit's r/wallstreetbets. Using ai to automate stock trading, this project aims to test the theory of, if you do the opposite of what ever jim cramer says, you'll make money.*

**Tech-Stack:** Frontend HTML/CSS/JavaScript — Dashboard UI with dark theme Tailwind CSS — Responsive styling Chart.js — Real-time equity performance charts Vanilla JS — Signal feed, trade panel, portfolio management Backend Python 3.14+ — Core runtime FastAPI — REST API framework SQLAlchemy — ORM for database models Alembic — Database schema migrations Anthropic Claude API — Sentiment analysis & ticker extraction Alpaca Trade API — Brokerage integration (paper + live trading) Playwright — X/Twitter scraping automation asyncpg — Async PostgreSQL driver Database PostgreSQL — Primary data store (hosted on Supabase) Deployment Platforms Vercel — Hosting (Python/FastAPI backend) Supabase — PostgreSQL database & real-time subscriptions Alpaca — Trading API (paper trading for testing, live for production)
