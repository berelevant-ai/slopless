# How client-side file conversion works (and why we never upload your files)

At Kalenux we run File Converter Free, a tool that converts 30+ file formats entirely in the browser. No uploads, no server, your files never leave your device. Over 100,000 people use it every month, and the privacy guarantee is the whole point.

Here is how client-side file conversion actually works, and why we built it that way.

## The usual model: upload, convert, download

Most online converters send your file to a server, convert it there, and send it back. It is simple to build, but it means your document, image, or video, sometimes sensitive, sits on someone else's machine. For a lot of people that is a dealbreaker, and it should be.

## The client-side model: convert where the file already is

The file is already on the user's device. So the conversion should happen there too. Nothing uploads, nothing is stored, nothing can leak from a server because the server never sees the file.

The catch: conversion is heavy work, and the browser is the runtime. That is where the engineering gets interesting.

## WebAssembly does the heavy lifting

Mature conversion tooling, image codecs, document parsers, media transcoders, is written in C and C++. We compile that to **WebAssembly** so it runs in the browser at near-native speed. The decades of battle-tested conversion logic doesn't get rewritten in JavaScript; it gets compiled to run client-side.

- **Images** decode and re-encode through WASM-compiled codecs.
- **Documents** are parsed and rendered in-browser.
- **Heavier jobs** run off the main thread in Web Workers, so the UI stays responsive while a file converts.

## A PWA, so it works like an app

File Converter Free is a Progressive Web App. It can be installed, it loads instantly on repeat visits, and the core converters work offline, because once the WASM modules are cached, there is no server round-trip to depend on. A converter that runs offline is the clearest possible proof that your files are not going anywhere.

## Why we built it this way

Privacy is not a feature you add later; it is an architecture you choose up front. By deciding the file never leaves the device, every other decision, WASM, workers, offline PWA, follows naturally. The result is a tool people trust with documents they would never upload to a stranger's cloud.

That is the kind of constraint we like: pick the hard guarantee, then engineer everything else to honor it.
