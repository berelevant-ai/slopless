# I built a niche car calculator site from scratch — 1,670 impressions, 0 clicks, and why I'm not worried

I've been quietly building AutoCalcHub ( https://autocalchub.com ) — a free niche site with car calculators and buying guides targeting US English search traffic.
No framework, no CMS. Pure HTML, CSS, and vanilla JS hosted on GitHub Pages.
What it is
13 free tools covering everything from car loan payments ( https://autocalchub.com/tools/car-loan-calculator.html ) to EV charging costs ( https://autocalchub.com/tools/ev-charging-cost-calculator.html ), paired with 32 blog posts across five categories: Buying, Financing, Running Costs, EV, and Ownership.
The goal is simple: rank for long-tail car finance keywords, monetize with AdSense, and eventually add affiliate links.
Current numbers (after ~6 weeks)

38 pages submitted to Search Console
15 indexed, 23 still pending
1,670 impressions, 0 clicks
Average position: 74.5
Best page: How Much Car Can I Afford ( https://autocalchub.com/blog/how-much-car-can-i-afford.html ) — sitting at position 18.9

Why 0 clicks isn't a crisis
SEO on a brand new domain takes 3–6 months before organic traffic starts. The impressions tell me Google is finding and evaluating the pages. Position 18.9 on one page means I'm almost on page 1 — that's the one I'm focused on pushing over the line.
The technical stack

GitHub Pages for hosting (free)
Cloudflare for the domain
Google Analytics 4 + Search Console
Schema markup (JSON-LD) on every tool and blog page
llms.txt for AI crawler discoverability

What's next
Publishing 3 blog posts + 1 tool every week. AdSense pending approval. Once that's live, the plan is affiliate links for auto insurance and car loan comparisons.
Happy to answer questions about the niche site model or the SEO approach.
