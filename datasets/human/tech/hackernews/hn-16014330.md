# Ask HN: Usefulness of CSS Framework agnostic html tags transpiler?

<!-- author: superasn; created: 2017-12-27T12:22:11Z; score: 5 -->

I was wondering how useful it would be to create a HTML tag transpiler to create a CSS framework agnostic HTML files. So instead of writing code like this for say, a Panel Boostrap: <div class="panel panel-default"> <div class="panel-heading">Title</div> <div class="panel-body">A Basic Panel</div> </div> Bulma: <nav class="panel"> <p class="panel-heading">Title</p> <div class="panel-block">A Basic Panel</div> </div> We can just write code like this <panel> <panel-heading>Title</panel-heading> <panel-body>Body</panel-body> </panel> So now the transpiler can automatically create HTML files in the dist directory (via Webpack)? This way you can switch CSS frameworks and you also don't need to learn classes, etc for each framework? Just an idea.. wondering what the pros and cons are?
