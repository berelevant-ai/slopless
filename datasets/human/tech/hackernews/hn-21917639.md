# Open-source YouTube alternative that also supports audio and images, (NodeJS)

<!-- author: mayeaux; created: 2019-12-30T23:30:08Z; score: 9 -->

I am open-sourcing my very robust YouTube alternative that supports image and audio uploads and has livestreaming built in, monetization through Stripe, lots of amazing features. You can check it out 'in the wild' here: https://nodetube-1.herokuapp.com Source code is available here: https://github.com/mayeaux/nodetube Also for people with Heroku I just created a Deploy To Heroku Button, the link to follow is here: https://heroku.com/deploy?template=https://github.com/mayeaux/nodetube That's still with ephemeral file-storage, I am going to writeup how you use add Backblaze to add cloud storage using just your phone number, but your first created account will be an admin account so you can check out the admin features and test uploading different files yourself. FFmpeg is rolled into the app automatically so many different video file formats are supported out of the box. Also check out the Wiki which includes Linux, OS X and Docker installations: https://github.com/mayeaux/nodetube/wiki
