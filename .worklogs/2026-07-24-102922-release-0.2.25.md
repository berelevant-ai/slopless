# Release 0.2.25

## Summary

Prepared Slopless 0.2.25 with every reviewed detection change after 0.2.24.
The release retains the existing public API and npm provenance workflow.

## Decisions made

- Used a patch version because the release broadens existing rules without
  changing rule IDs, exports, CLI arguments, or package interfaces.
- Kept publication in the GitHub release workflow instead of publishing from a
  local checkout.
- Included all four post-0.2.24 feature commits because each had completed
  fixture, corpus, and adversarial review.

## Verification

- `pnpm validate` passes.
- The release Specular specification lints and verifies.
- All 19 Fixture3 suites match approved output.
- `package.json` and the planned release tag both use 0.2.25.
