## CI fix (release was blocked by a pre-existing infra break)
The required `Validate` check failed at `cargo install --git .../agent-quality-controls/guardrail3 g3ts`
- a PRIVATE cross-org repo CI can't clone (it only worked while the rust-cache held the binary; cache
missed). Two findings: there is no public g3ts binary to fetch (not on crates.io, no guardrail3
releases), and CI never actually ran g3ts anyway (no `g3ts validate` step; `pnpm run validate` does not
call it). So the install was dead + broken. Removed the `cargo install g3ts` step plus the
`rust-toolchain` and `rust-cache` steps that only supported it. CI is now checkout -> pnpm -> node ->
`pnpm install --frozen-lockfile` -> `pnpm run validate`. The g3ts gate stays enforced at commit time via
the local pre-commit hook. Running g3ts *in CI* is a later task that first needs a public g3ts binary.
