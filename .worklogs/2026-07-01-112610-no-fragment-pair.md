# No-fragment pair detector

## Summary

Added coverage for adjacent clipped `No X. No Y.` prose beats under the existing `fragment-stacking` rule. The detector now catches pairs such as `No implant. No brain surgery.` and `No fever. No rash.` without lowering the broader fragment-stack threshold.

## Decisions Made

- Kept the rule ID as `syntactic-patterns:fragment-stacking` because the defect is fragment cadence, not a negation reframe.
- Added a targeted two-sentence `no-fragment` path while leaving the general fragment stack requirement unchanged.
- Split detector logic into `src/rules/syntactic-patterns/repetition/private/fragment-stack-detector.ts` after validation caught the 400-line file limit.
- Added no-hit guards for full factual clauses such as `No implant was used. No brain surgery was performed.`
