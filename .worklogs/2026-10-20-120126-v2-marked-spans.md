# V2 Marked Spans

## Summary

Clarified expected labels in root `AGENTS.md`: positive judgments identify the offending wording through marked spans within the passage. Negative judgments omit spans and hit explanations.

## Decisions

- Use character ranges to identify wording already stored in the passage, including cross-sentence constructions.
- Keep explanations about the writing problem short and include them when needed. Keep historical source information, run history, and review transcripts outside judgments.
- Update the target instructions only. The existing dataset schema, labels, and runners remain unchanged until the V2 implementation.
