# Textlint 15.8 update

## Goal

Update the Textlint runtime and its two directly imported type packages to
15.8.0 as one synchronized change, with unchanged Slopless behavior.

## Approach

1. Update `textlint`, `@textlint/ast-node-types`, and `@textlint/types` to
   15.8.0 together.
2. Regenerate the lockfile and install it under the repository's supply-chain
   policy.
3. Run validation, all Fixture3 suites, Specular, and the dependency audit.
4. Merge the combined change and close the three superseded single-package
   Dependabot pull requests.

## Key Decisions

- Keep the three packages on one version because Slopless imports Textlint's
  public AST and rule types directly.
- Do not merge the three generated pull requests separately; that would place
  mismatched Textlint package versions on `main` between merges.

## Files To Modify

- `package.json`
- `pnpm-lock.yaml`
