# Marked Excerpt Trial

## Goal

Test the exact proposed single-field excerpt and target-marker instructions against the existing paragraph/context requests. Measure retained hits, false positives and findings caused by defects outside the marked target.

## Approach

- Extend the existing experimental `runners/article-context.mjs` rather than the production runtime. Keep Jev, frozen rule definitions, criteria and thresholds unchanged.
- Put the native target and surrounding writing in `state.text`, marking the target with `<target kind="...">`. Replace shared reading instructions with the four paragraphs shown to the user and explicitly ask about the marked target.
- Evaluate the existing 120 structural controls with full question batches. Reuse request-identical baseline answers and preserve the original labels; separately report the three explained-remit examples now required as wording hits by the user.
- Add thirty localization controls derived from ten existing positive examples in three structures. Their passages contain a named defect outside a clean target; positive dataset snippets identify the context defect, while the targeted evaluation expects silence on the clean node.
  - Independently review these labels and target boundaries before inference. Do not expose holdouts or tune prompts after seeing the results.
- Run the marked arrangement on all 123 paragraphs and thirty headings of the unchanged BGaming article. Review added and removed assignments and the original named no-hit judgments.
- Save prepared excerpts, exact questions, request hashes, raw answers, timings and comparisons under `runners/results/`. Deduplicate repeated question objects through the existing recording format.

## Decisions

- Derive excerpts and marker placement from native source ranges and existing extracted contexts. Keep the original report range separate from the excerpt.
- Judge genuine positives as well as no-hits in every structure. Count off-target errors separately from classification errors.
- Keep the two whole-text checks outside this paragraph-input trial. Change no production source, accepted model fixture output or protected data.

## Files

- `runners/article-context.mjs` gains marked preparation and input construction.
- `datasets/ai-synthetic/passages/000141-marked-target-localization-development.*` stores the reviewed localization controls.
- `runners/results/marked-excerpts-*` records the structural, localization and article trials; a report and worklog record verified results before committing.
