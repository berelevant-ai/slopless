# Coverage

- Specular checks ownership of the sourced classification data and removal of the unsafe legacy fallback.
- Fixture3 occurrence probes check source ranges, one main action per independent clause, and excluded embedded verbs.
- Existing frozen 24-hit/24-no-hit examples test editorial decisions separately from grammar. Any changed label requires an explicit contradiction, not a desired score.
- Public Fixture3 diffs check all families and case/corpus correspondence. Full cadence-only corpus comparison measures additions, removals and severity changes against release 0.2.37 and the rejected candidate.
- Manual review, not source provenance or warning severity, determines whether a new finding is wanted.
