# Paragraph Location

Select every paragraph containing offending wording or a required part of the named construction. Read the complete article; judge participation rather than the paragraph in isolation. Mere background, a reference to the subject, or useful neighboring material is insufficient. Return no when the alleged defect is absent.

For buried-answer, select unnecessary material delaying the operative answer; preserve the question, useful reasoning and answer.

For repeated-explanation, select both the earlier explanation and its unnecessary later repetition. Preserve useful recaps and distinct later applications.
